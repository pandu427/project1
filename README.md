# Offline Coding Challenge - Frontend

React + TypeScript + Vite implementation of the supplied Todo challenge.

## Features
- Reverse chronological tasks
- Add/edit/delete tasks
- Done/undone toggle
- `localStorage` persistence using `todo.items.v1`
- Empty state and validation
- Accessible labels and keyboard-friendly controls
- Responsive three-panel UI based on the PDF mockup
- Custom hooks: `useTodos` and reusable `useLocalStorage`
- Vitest + React Testing Library tests

## Run
```bash
npm install
npm run dev
```
Open the Vite URL shown in the terminal (normally http://localhost:5173).

## Test
```bash
npm test
```

## Build
```bash
npm run build
```
